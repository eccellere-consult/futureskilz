# Learning path entry: Find the cause, not just the symptom

- **Skill Shot:** Find the cause, not just the symptom (root-cause-five-whys, version 0.1.0)
- **Skill Set:** Solve a problem that keeps coming back
- **Capability Module:** Problem solving at work
- **Role or domain path:** New joiner readiness › Operations (and any function)
- **Position:** After 'Describe a problem with facts'. Before 'Choose the problem to solve first' and 'Plan and test a fix'.
- **Prerequisites:** Describe a problem with facts: who, what, where, when and how big (the 5W2H step in the Problem Solving kit)
- **After this the learner can:** Trace a repeating problem, step by step, from what you can see to a cause you can fix, using five checkable whys.

## Next
- Try the 5 Whys tool on a real problem (/problem-solving/five-whys): Apply the method to a problem of your own, with checks.
- Find which problem to solve first with a Pareto chart (/problem-solving/pareto): When there are many problems, the data shows which few matter most.
- Show causes side by side with a fishbone (/problem-solving/fishbone): When one chain is not enough, a fishbone lays out several possible causes.
